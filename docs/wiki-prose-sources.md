# Wiki prose sources

Snapshot date: 2026-11-11. Brother Laz's writing is used with Brother Laz's
permission and credited to him, as recorded in [NOTICE](../NOTICE.md). These
documentation inputs are distinct from the mod's versioned game asset pack.
The original wiki files were copied without edits. The in-game exporter filters
technical material and repeated category listings without changing these sources.

The snapshot has 29 player guide pages (387,176 bytes) in `tools/wiki/pages/`
and eight cached HTML files (275,225 bytes) in `tools/wiki/class-texts/`, for
662,401 bytes total. Installation, loader/plugin setup, port history, Main Page
and the website's MediaWiki, Module and Template infrastructure are excluded.

Attribution below is inferred from each page's source-credit link, visible port
notes, generated sections and project-specific writing. It is not a line-by-line
authorship history. “Brother Laz” means his documentation converted to wiki markup,
with formatting, navigation or metadata supplied by this project. “Mixed” means
substantive project prose, generated lists or port notes accompany his writing.
